# 🌏 다함께 GO! 세계여행 v0.8

초등학생이 여러 나라의 **말·음식·생활·문화**를 여행하듯 탐색하고, 공통점과 차이를 존중하는 태도를 기르는 다문화교육용 React/PWA 웹앱입니다. 기본 배포 방식은 **GitHub Pages**이며 Gemini/OpenAI API 키 없이 작동합니다.

## v0.8 핵심 변화 — 세계의 말 + 이미지 탐험

- 기본 12개국의 표현을 **나라별 약 10개**로 확대: 인사·예절·학교·일상
- `🗣️ 말 도감` 메뉴 추가: 검색, 나라/분류 필터, 배운 말, 즐겨찾기
- 나라별 **플래시카드**: 뜻 뒤집기, TTS 듣기, 배웠어요, 즐겨찾기
- 메인 화면에 매일 바뀌는 **오늘의 세계 한마디**
- 기본 12개국에 **48개 로컬 SVG 교육용 이미지** 포함(풍경·음식·생활·문화)
- 나라별 `🖼️ 그림 탐험` 갤러리와 확대 보기
- 음식·생활·문화 화면에 관련 이미지 연결
- 그림 자료를 비판적으로 읽는 **이미지 기반 퀴즈** 추가
- 교사 콘텐츠 제작기에서 추가 표현 여러 개와 대표 이미지 파일을 함께 저장 가능
- 말 학습 배지 추가: 말 탐험가, 말 수집가, 내 마음의 한마디
- v0.1~v0.7 학생 진행 데이터와 호환

## 무료 사용

기본 여행, TTS, 이미지, 퀴즈, 여권, 말 도감, 교사 콘텐츠 제작, 무료 규칙 기반 문항 생성은 외부 생성형 AI API 없이 사용할 수 있습니다. Supabase는 여러 학생 기기의 데이터를 교사 화면으로 모을 때만 선택적으로 연결합니다.

## GitHub Pages 배포

1. 이 프로젝트의 파일/폴더를 GitHub 저장소 루트에 업로드합니다.
2. 저장소 `Settings → Pages → Source`에서 **GitHub Actions**를 선택합니다.
3. `main` 브랜치에 변경이 올라오면 `.github/workflows/pages.yml`이 자동으로 설치·빌드·배포합니다.
4. 배포 후 앱 오른쪽 아래 `🛠 확인`에서 버전이 `0.8.0`인지 확인합니다.

자세한 내용은 `GITHUB_PAGES_SETUP.md`, `TEST_CHECKLIST.md`, `SCHOOL_NETWORK_TESTING.md`를 참고하세요.

## 주요 기술

React + TypeScript + Vite + PWA + GitHub Pages. 선택 기능으로 Supabase Auth/PostgreSQL/Realtime을 사용합니다.
