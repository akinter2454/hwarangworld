# 🌏 다함께 GO! 세계여행 v1.1.0

초등학생이 실제 사진, 세계의 말, 음식·생활·문화 자료를 탐색하며 **다름을 만나고 같음을 발견하는** 다문화 세계여행 학습 플랫폼입니다.

## v1.1 정식 수업 활용 기능

- 12개국 세계여행 + 교사 제작 여행지
- 나라별 여러 표현, TTS, 플래시카드, 말 도감
- Wikimedia Commons 사전 선별 실사진 48장 + 교사 검토 사진
- **사진 관찰 미션**: 보이는 것 / 궁금한 것 / 사진만으로 알 수 없는 것
- **두 나라 사진 비교**: 풍경·음식·생활·문화 같은 주제로 나란히 비교
- **사진-말 연결 게임**: 사진을 풍경·음식·생활·문화 개념과 연결
- **세계여행 포토북**: 사진 관찰·비교·여행일기를 자동으로 모아 인쇄/PDF 저장
- **세계시민 탐험가 인증서**: 기본 12개국 완주 후 발급일·인증번호와 함께 인증서 발급, 브라우저 인쇄/PDF 저장
- 여권, 별, 수집품, 배지, 여행일기
- 교사용 콘텐츠 제작기, 사진 자료 관리실, 학급 미션
- 쉬운 한국어, 다국어 빠른 안내, 활동지 출력
- Gemini/OpenAI API 없이 무료 로컬 문항 생성·분석
- 선택적으로 Supabase 학급 동기화
- GitHub Pages 자동 배포

## GitHub Pages 업데이트

기존 GitHub Pages 저장소의 `.github` 폴더는 그대로 두고 v1.1의 `src/`, `public/`, `package.json`, `vite.config.ts` 및 루트 문서를 같은 위치에 업로드/교체합니다. Commit하면 기존 GitHub Actions가 자동으로 빌드·배포합니다.

자세한 절차는 `UPGRADE_TO_V11.md`를 참고하세요.

## 데이터 호환성

v0.1부터 사용한 `multicultural-world-tour-player-v1` 저장 키를 그대로 유지합니다. v1.1에서도 같은 저장 키를 유지합니다. 기존 학생 기록에는 사진 관찰·비교 데이터와 인증서 발급 정보가 없을 경우 빈 값이 자동 보완됩니다.

## 학생 사진 안전 원칙

학생에게 실시간 인터넷 이미지 검색을 제공하지 않습니다. 기본 실사진은 코드에 사전 등록한 Wikimedia Commons 자료만 사용하며, 교사 추가 자료도 미리보기·안전 체크·출처 확인을 거쳐야 공개됩니다. 사진 한 장으로 한 나라나 사람 전체를 일반화하지 않도록 관찰 활동 자체에 미디어 리터러시 질문을 포함합니다.
